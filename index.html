🚀 شروع سریع در ۶ قدم

  1. از منوی 📁 فایل → فایل جدید یک فایل جدید بساز.
  2. کارت‌های صفحه اصلی را پر کن (بیمار، شرح حال، آزمایشات و ...).
  3. از پنل کناری 🎨 قالب و ظاهر ارائه تم و فونت را تنظیم کن.
  4. با ⧉ در لیست ترتیب، بخش‌های تکراری بساز.
  5. با 👁 پیش‌نمایش یا Ctrl+P خروجی را ببین.
  6. از منوی 📤 خروجی فایل PowerPoint یا PDF بگیر.
نکته: تغییرات خودکار در مرورگر ذخیره می‌شوند. برای نگهداری دائمی، حتماً با Ctrl+S روی فایل ذخیره کن.

📁 فایل و ذخیره‌سازی

  • فایل جدید (Ctrl+N) — شروع از صفر.
  • باز کردن فایل (Ctrl+O) — باز کردن فایل .cps.json.
  • فایل‌های اخیر — فقط در Chrome/Edge.
  • ذخیره (Ctrl+S) — بازنویسی فایل فعلی.
  • ذخیره با نام جدید (Ctrl+Shift+S).

نشانگر وضعیت: 🟢 ذخیره شده · 🟠 تغییرات ذخیره‌نشده · ⚪ ذخیره نشده.

اگر مرورگر را ببندی و Ctrl+S نزده باشی، تغییرات از بین می‌روند.

📝 فرم‌های اطلاعات بیمار

  • کلید روشن/خاموش کنار هر کارت — برای حذف/افزودن بخش.
  • جابجایی — از دسته ⋮⋮ بکش.
  • کپی — با ⧉ در لیست ترتیب.
  • دیکته صوتی — روی 🎤 بزن یا Ctrl+Shift+D.
  • ROS — با هر کلیک: خنثی → مثبت (+) → منفی (−).
  • آزمایشات — ستون‌های واحد/محدوده/تفسیر قابل فعال/غیرفعال.
  • روند تغییرات — مقادیر را با کاما جدا کن (مثلاً 1.3, 1.8, 2.5).

🖼 کارت تصاویر

  • افزودن تصویر — چند فایل همزمان.
  • برش — نسبت‌های آماده ۱۶:۹، ۴:۳، ۱:۱ یا آزاد + چرخش و آینه‌ای.
  • عنوان اسلاید، زیرنویس، سبک عنوان، آیکون — همه مستقل.

📄 اسلایدهای خالی سفارشی

در انتهای صفحه اصلی، کارت Custom Blank Slides قرار دارد:

  • عنوان، متن، فونت، اندازه، چیدمان، جهت، سبک عنوان، آیکون — همه مستقل.
  • دیکته صوتی روی کادر متن هم موجود است.

🎈 نوار شناور قالب‌بندی

متن را در هر کادری انتخاب کن → نوار شناور ظاهر می‌شود → روی دکمه دلخواه بزن. دکمه‌ها: B (پررنگ)، H (هایلایت)، ! (تأکید)، S (خط‌خورده)، R/B/G/O/P (رنگ‌ها).

در موبایل، نوار در پایین صفحه و بالای کیبورد ظاهر می‌شود.

🎨 قالب و ظاهر ارائه

  • تم رنگی — Azure، Teal، Dark، Violet، Slate، Rose، Navy، Custom.
  • عنوان اسلایدها — فونت، اندازه (۲۲ تا ۴۴)، سبک (۱۰ گزینه)، رنگ اختصاصی.
  • متن اسلایدها — فونت، اندازه، فاصله خطوط، بولت.
  • پاورقی و شماره — متن و نمایش/مخفی.

🤖 دستیار AI

  1. روی هوش مصنوعی → کپی پرامپت AI بزن.
  2. پرامپت را در چت AI پیست کن و شرح حال را اضافه کن.
  3. پاسخ JSON را کپی کن.
  4. روی هوش مصنوعی → ورود پاسخ AI بزن و پیست کن.
  5. روی ✓ اعمال بزن.
Replace existing data را چک کن اگر می‌خواهی داده‌های قبلی پاک شوند.

  • 📄 PDF — آماده چاپ.

🚀 Quick Start in 6 Steps

  1. Create a new file from 📁 File → New File.
  2. Fill the main page cards (patient, history, labs, …).
  3. Set theme and font from sidebar 🎨 Theme & Appearance.
  4. Use ⧉ in the order list to duplicate sections.
  5. Preview with 👁 Preview or Ctrl+P.
  6. Export to PowerPoint or PDF from 📤 Export.
Tip: Changes auto-save in the browser. For permanent storage, always save with Ctrl+S.

📁 File & Storage

  • New File (Ctrl+N) — start fresh.
  • Open File (Ctrl+O) — open a .cps.json file.
  • Recent Files — Chrome/Edge only.
  • Save (Ctrl+S) — overwrite current file.
  • Save As (Ctrl+Shift+S).

Status indicator: 🟢 saved · 🟠 modified · ⚪ not saved.

If you close the browser without saving (Ctrl+S), changes are lost.

📝 Patient Forms

  • Toggle switch next to each card to show/hide in slides.
  • Reorder — drag the ⋮⋮ handle.
  • Duplicate — use ⧉ in the order list.
  • Voice dictation — click 🎤 or press Ctrl+Shift+D.
  • ROS — click cycles neutral → positive (+) → negative (−).
  • Labs — enable/disable Unit/Range/Interpretation columns.
  • Lab Trends — separate values with commas (e.g. 1.3, 1.8, 2.5).

🖼 Images Card

  • Add images — multiple files at once.
  • Crop — preset ratios 16:9, 4:3, 1:1, or free + rotate and flip.
  • Slide title, Caption, Header style, Icon — all independent.

📄 Custom Blank Slides

At the bottom of the main page, the Custom Blank Slides card:

  • Title, text, font, size, layout, direction, header style, icon — all independent.
  • Voice dictation is available on the textarea.

🎈 Inline Format Toolbar

Select text in any field → a floating toolbar appears → click any button. Buttons: B (Bold), H (Highlight), ! (Warning), S (Strikethrough), R/B/G/O/P (colors).

🎨 Theme & Appearance

  • Color Theme — Azure, Teal, Dark, Violet, Slate, Rose, Navy, Custom.
  • Slide Titles — font, size (22–44), style (10 options), custom color.
  • Slide Text — font, size, line spacing, bullet.
  • Footer & Number — text and visibility toggles.

🤖 AI Assistant

  1. Click AI → Copy AI Prompt.
  2. Paste the prompt in an AI chat and add the patient history.
  3. Copy the JSON response.
  4. Click AI → Paste AI Response and paste.
  5. Click ✓ Apply.

📤 Export

  • 📄 PDF — ready to print.
  • 🌐 Self-contained HTML — single file, works anywhere.
  • 🖼 PNG Slides — one image per slide.

🔧 Troubleshooting

Persian letters disconnected in output: refresh the page; pick Vazirmatn or IRANSans.

Dictation not working: use Chrome/Edge; allow microphone in browser settings.

Recent Files empty: works only in Chrome/Edge.

New slide not in export: check the green toggle next to its card.
